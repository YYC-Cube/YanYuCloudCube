# YanYu Cloud Cube 模块总览

本仓库按行业与能力模块化组织，统一提供可推送的示例内容与占位文件，便于后续持续集成与扩展。

## 模块目录

- `yyc3-agr` — 智慧农业
- `yyc3-fb` — 餐饮服务
- `yyc3-fn` — 股票金融
- `yyc3-gov` — 智慧城市
- `yyc3-hr` — 人力资源
- `yyc3-med` — 医疗健康
- `yyc3-media` — 媒体娱乐
- `yyc3-manu` — 智慧制造
- `yyc3-core` — 智能编程
- `yyc3-cultural` — 智能文创
- `yyc3-edu` — 智能教育
- `yyc3-energy` — 能源管理
- `yyc3-env` — 环境保护
- `yyc3-law` — 法律服务
- `yyc3-log` — 智慧物流
- `yyc3-ent` — 实体经管
- `yyc3-real` — 地产建筑
- `yyc3-retail` — 智慧零售
- `yyc3-traffic` — 智能交通
- `yyc3-tourism` — 旅游酒店
- `yyc3-elder` — 智慧养老
- `yyc3-api` — 技术集成
- `yyc3-cdc` — 数据中心
- `yyc3-fin` — 金融
- `yyc3-finance` — 金融科技
- `yyc3-Edge` — 边缘数据中心

## 示例内容与占位文件

- 每个模块统一包含四个子目录：`cloud`、`cube`、`yan`、`yu`。
- 每个子目录均提供：`README.md`（用途说明）、`package.json`（最小化工程占位）、`src/README.md`（代码目录占位）。
- 已对缺失的模块补齐结构与占位文件，保证可推送与可持续集成。

## 使用说明

- 可直接在各子目录下替换 `package.json` 与脚本，`src/` 目录为业务代码放置处。
- 如需定制模块结构，请保持以上规范，便于自动化脚本与流水线识别。
